# DriveCare Frontend

Dana Group car service platform for car owners to book service, track vehicle repairs, approve estimates, and receive pickup updates. Built with Next.js 15, TypeScript, Tailwind CSS v4, Framer Motion, Shadcn UI, TanStack tools, Zustand, Sonner, Recharts, React Hook Form, Zod, React Day Picker, React Dropzone, and Next Themes.

## Getting Started

```bash
yarn install
yarn dev
```

Open [http://localhost:3000](http://localhost:3000).
